# Version pinning uses ~= (compatible release). Note what that actually means:
# a two-component spec like ~=1.37 expands to ">=1.37, <2.0" — patch AND minor
# updates are allowed, only major bumps are blocked. Blocking minor bumps would
# require a three-component spec (~=1.37.0 → ">=1.37.0, <1.38").
#
# Two-component specs are deliberate here: we want minor updates (st.fragment,
# used for the live stats, arrived in a Streamlit minor release), while still
# being protected against major-version API breaks.
